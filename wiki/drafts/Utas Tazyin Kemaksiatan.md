# Utas Tazyin Kemaksiatan (Bukowski Style)

## Arah Kreatif

- **Tujuan Konten:** Menyajikan konsep *Tazyin Kemaksiatan* dalam bentuk utas X 10-postingan yang puitis, mentah, dan berkarakter (gaya Charles Bukowski) menggunakan aturan *stop-slop*.
- **Target Pembaca/Penonton:** Pengguna X pengikut akun @jamaahquba, pemuda muslim, dan publik umum.
- **Hook (Pikat):** Setan tidak memakai jubah merah bertanduk. Dia humas berkemeja necis di sudut bar malam.

## Kerangka Utama / Poin Kunci

- Setan mengaburkan kemaksiatan dengan label-label bagus (tazyin).
- Contoh re-label dosa: riba jadi keuntungan, suap jadi uang kopi, khamar jadi minuman spiritual.
- Sumpah palsu Iblis meniru kepedulian tulus (nasih).
- Hilangnya rasa malu dan terlepasnya pakaian ketakwaan.
- Ajakan menghadapi cermin kejujuran dengan menyebut dosa sesuai nama aslinya.

## Draf Konten / Naskah / Postingan

### [Untuk X: Utas / Postingan Tunggal]

```
1/
Setan tidak memakai jubah merah bertanduk. Dia humas berkemeja necis di sudut bar malam, menyodorkan gelas berisi racun. Dia menyebutnya anggur madu. [[Tazyin Kemaksiatan]]
```

```
2/
Trik ini bermula di surga. Iblis menunjuk pohon terlarang, lalu berbisik kepada kakek kita: "Ini pohon keabadian." Label indah yang menipu akal sehat. [[tafsir-sadi-iblis-adam]]
```

```
3/
Dia mewariskan trik itu ke jalanan kota hari ini. Kemaksiatan butuh kemasan. Dosa yang telanjang menakutkan untuk didekati.
```

```
4/
Lintah darat berganti nama menjadi penyedia modal. Riba berubah sebutan menjadi keuntungan. Kamu menandatangani kertas itu. Lehermu tergadai saat pena menyentuh kertas.
```

```
5/
Pejabat menyelipkan amplop di bawah meja kayu kusam. Mereka tidak menyebutnya suap. Istilah uang kopi atau tanda terima kasih membuat transaksi terasa bersih.
```

```
6/
Racun di dalam botol kaca gelap berlabel minuman spiritual. Kamu meminumnya hingga muntah di toilet busuk, mengira sedang merayakan kebebasan.
```

```
7/
Pembohong menamai dusta mereka taktik pemasaran. Pezina menyebut perselingkuhan sebagai pelarian emosional. Kita memoles cermin agar tidak melihat monster di dalamnya.
```

```
8/
Setan tahu akal manusia rapuh saat syahwat mengetuk pintu. Dia cukup mencarikan kata lain yang ramah bagi telinga tetangga. [[Waswasah Setan]]
```

```
9/
Tatkala ketakwaan di dada menguap, pakaian lahiriah ikut lepas. Kamu berdiri telanjang di bawah lampu jalan, kehilangan benteng pertahanan terakhir: rasa malu. [[Fitrah Rasa Malu]]
```

```
10/
Sebut dosa dengan nama aslinya. Jangan memoles lumpur menggunakan bedak. Akui kesalahanmu, buang racun itu, dan mulailah bersujud.
```
